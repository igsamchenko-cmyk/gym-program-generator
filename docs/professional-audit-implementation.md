# Реалізація експертного аудиту після 0749462

Оновлено: 3 вересня 2026 року.

| Пункт аудиту | Реалізація |
| --- | --- |
| Імпорт обходив скринінг | Спільні посилання та JSON-копії тепер завантажують дані, але не відкривають план до проходження нового локального скринінгу. Виправлено також гонку подвійного ефекту React StrictMode. |
| Не було повного редактора | Для кожної вправи редагуються підходи, повтори, RIR, темп, пауза й планова вага. Можна додати та видалити власну вправу. |
| Журнал не адаптував план | Готовність ≤2, session-RPE ≥9 або біль ≥4/10 автоматично зменшують наступну сесію; два послідовні сигнали активують відновлювальне дозування. Автокорекцію можна вимкнути. |
| Груба модель непрямих підходів | Коефіцієнт непрямої роботи тепер залежить від рухового патерну та м’яза, а не дорівнює 0.5 для всіх випадків. Нижні орієнтири доповнюються, коли це не порушує стелю або ліміт часу; невирішений дефіцит показується явно. |
| Вага не відповідала повторенням/RIR | Планова вага обчислюється оберненою формулою Epley для конкретного діапазону повторів і RIR. Після сесії орієнтир оновлюється за найкращим фактичним підходом. |
| Health був лише трекером | Додано конкретні аеробні сесії, вид активності, тривалість, помірну інтенсивність, поступове збільшення та критерій повторення/переходу тижня. |
| Категоричний персоналізований текст | Прибрано твердження про «10+» і «20 років» та абсолютне «обсяг більше не важіль»; формулювання стали нейтральними й індивідуальними. |
| Не було робочого процесу тренера | Додано до 20 локальних профілів клієнтів, журнал ревізій, план/факт, відвідуваність за 28 днів, найкращі e1RM по вправах і видалення помилкової сесії. |

Нові правила покриті unit- та Playwright E2E-тестами для desktop і mobile. Застосунок залишається навчальним інструментом і не замінює медичну оцінку або індивідуальне рішення тренера.
