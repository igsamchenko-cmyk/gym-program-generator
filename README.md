# Gym Program Generator

Конструктор програм силових тренувань з повноцінною періодизацією — не список вправ, а мезоцикл на 5–11 тижнів із делоадами, розділеним RIR і важкими блоками.

## Чому не типовий генератор

Більшість генераторів тренувань видають один незмінний список вправ. Тут — рухомий макроцикл:

- **RIR розділено за SFR.** Базові рухи й ізоляція мають окремий RIR у кожному тижні: втома переноситься туди, де вона дешевша.
- **Одна змінна за раз.** У межах тижня росте або обсяг, або близькість до відмови — ніколи одночасно, інакше незрозуміло, що дало ефект.
- **Важкі блоки 3–6 повторів.** Ротуються між двома найнавантажуванішими рухами дня — зона, яку типовий гіпертрофійний діапазон 8–15 не зачіпає.
- **18 підспецифікацій м'язів** замість 10 груп: ширина / товщина / низ спини окремо, литковий проти камбалоподібного, ключична порція грудей, довга головка трицепса.
- **Довжина макроциклу залежить від стажу** — 5 тижнів новачку, 7 середньому, 11 просунутому.
- **Вік, стаж, ціль і баланс визначають готовність до вправи.** Новачки спершу отримують стабільні рухи, які не вимагають уже сформованої відносної сили; підлітки-новачки — лише початкову складність. Просунуті варіанти на кшталт брусів з додатковою вагою відкриваються тільки дорослому з відповідним стажем. Після 35 для гіпертрофії та здоровʼя пріоритет отримують стабільні варіанти з кращим співвідношенням стимулу до технічної втоми; досвідчений силовик зі стабільним контролем зберігає специфічні вправи зі штангою. Стать впливає на обсяг і відпочинок, але не використовується як ярлик сили чи технічної готовності.
- **Робочі ваги рахуються по тижнях** від введеної робочої ваги — відсоток прописаний у кожній фазі мезоциклу, включно з делоадом (60 %) і важким блоком (+12 %).
- **Пояснюваність.** Кожен вибір вправи можна розгорнути й побачити причину: вік, обмеження, пріоритет, підспецифікація.
- **Власна розкладка.** Крім готових спліт-шаблонів (фулбоді, upper/lower, PPL) можна зібрати довільний спліт, обираючи групи м'язів для кожного дня — движок сам підбере обсяг, порядок і підспецифікації.
- **Ліміт часу й календар.** Якщо сесія не вкладається у вказаний час, обсяг зрізається з ізоляції; якщо дні тижня близько один до одного, конструктор попереджає про недостатнє відновлення спільно навантажених груп.
- **98 локальних схем вправ.** У картці техніки є початкова й кінцева фази руху; зображення не залежать від зовнішніх посилань.
- **Світла й темна теми.** Обидві мають окремий фітнес-фон, а вибір теми зберігається в браузері.

## Структура

```
index.html                    — точка входу
src/main.jsx                  — монтування React-дерева
src/TrainingConstructor.jsx   — UI: анкета, картки вправ, панелі обсягу й правил
src/engine.js                 — чиста логіка без React: генерація мезоциклу, RIR, обсяг, розминка
src/data/exercises.js         — база з 98 вправ
src/data/labels.js            — довідники й тексти (спільні для движка й UI)
public/exercise-media/         — 98 локальних схем вправ
public/fitness-background-*.webp — фони світлої й темної тем
src/__tests__/                — Vitest: 33 тести на движок
vite.config.js                — конфігурація білда
.github/workflows/deploy.yml  — тести → білд → публікація на GitHub Pages при push у main
```

`engine.js` не залежить від React і DOM, тому його можна тестувати й перевикористовувати окремо від UI — саме на ньому побудовані тести нижче.

## Тести

```bash
npm test         # один прогін
npm run test:watch
```

33 тести у `src/__tests__/` перевіряють генератор напряму, без рендеру UI: відсутність дублікатів вправ у межах дня, дотримання вікових і фізичних обмежень, пороги технічної та силової готовності для новачків, однакову безпеку автоматичного добору й ручної заміни, мінімальну повноту автоматичного дня, підлогу RIR і заборону важких блоків/тест-тижнів для підлітків незалежно від обраного рівня стажу, стійкість до пошкодженого чи неповного профілю (застарілий `localStorage`, випадковий об'єкт замість профілю), коректність розрахунку ваг по тижнях і часу сесії для односторонніх вправ. CI (`deploy.yml`) не задеплоїть застосунок, якщо тести червоні.

## Автономність

Застосунок **не залежить від Claude чи будь-якого зовнішнього сервісу**. Це звичайний React-застосунок на Vite:

- профіль, робочі ваги та ручні заміни вправ зберігаються в `localStorage` браузера;
- експорт у Excel працює через бібліотеку `exceljs`, підвантажену лінивим `import()` лише в момент кліку — вона не входить у стартовий бандл (приблизно 262 КБ замість понад 1.2 МБ);
- жодних викликів до Claude API, мережевих запитів чи зовнішніх сервісів під час роботи немає.

## Деплой на GitHub Pages

Репозиторій уже містить workflow (`.github/workflows/deploy.yml`), який автоматично збирає й публікує застосунок при кожному push у гілку `main`.

Щоб увімкнути один раз:

1. `Settings → Pages → Source` → обрати **GitHub Actions**.
2. Зробити будь-який push у `main` (або запустити workflow вручну через вкладку `Actions → Deploy to GitHub Pages → Run workflow`).
3. Через 1–2 хвилини застосунок буде доступний на `https://<username>.github.io/gym-program-generator/`.

Шлях у `vite.config.js` (`base: "/gym-program-generator/"`) прив'язаний до назви цього репозиторію — якщо форкаєш під іншою назвою, онови це значення.

## Методологічна основа

Логіка мезоциклів, розділення RIR за SFR, ротація важких блоків і правило однієї змінної за тиждень побудовані на основі особистої 11-тижневої програми периодизації користувача проєкту — досвідченого атлета (22 роки стажу). Конструктор узагальнює цю структуру під довільний стаж, вік, стать, кількість днів і доступне обладнання (зал, гантелі, резинки, вага тіла).

## Застереження

Це навчальний інструмент, не медична порада. Прогресія ваг, важкі блоки й тестові тижні розраховані на здорову людину без гострих травм — за наявності болю, хронічних станів чи перерви після травми варто спершу проконсультуватися з лікарем.
